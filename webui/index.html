MCP — MODEL CONTEXT PROTOCOL

webcrawl ships a stdio MCP server that exposes these tools to hosts like Claude Desktop, Cursor, Windsurf, VS Code and Continue. Toggle a tool off to stop exposing it (the change persists and is applied the next time a host launches the server).

Tools

MCP servers the agent can draw on. Enable a server to advertise it to Agent-mode runs; toggle, test (static validation) or remove entries. Add servers from Templates or Import.

Save the current set of enabled servers as a reusable profile, or apply a built-in / saved profile. Applying a profile enables exactly its servers.

Paste a client MCP JSON block ({"mcpServers":{…}} or a single server). webcrawl validates it, previews each server and masks secrets before you save. Nothing is executed on import.
